# ESP32-lora-pager
Source code and supporting files for the ESP32 LoRa powered paging device

LoRa_Enclosure_Design_Pack_Prototype -> The 3D printed prototype case and all related files.

firmware.ino -> Source code firmware written in the Arduino IDE

pager.kicad_pcb -> KiCad PCB file

pager.kicad_pro -> KiCad Project file

pager.kicad_sch -> KiCad PCB schematic

pager_rev1_gerbers.zip -> Gerbers for ordering PCB from a factory

print.pdf -> Printed render of the final PCB.
